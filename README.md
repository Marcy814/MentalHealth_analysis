# MentalHealth_analysis
# Analyse et Prédiction de la Santé Mentale des Étudiants

## Description du Projet
Ce projet vise à analyser les données de santé mentale des étudiants et à prédire leur état en fonction de divers facteurs académiques et démographiques. Les données ont été collectées via un sondage à l'Université de Malaisie.

## Objectifs
- Comprendre les relations entre la santé mentale et la performance académique.
- Comparer les performances de trois algorithmes de Machine Learning.
- Identifier les facteurs les plus influents dans la prédiction de la santé mentale.

## Données
L'ensemble de données contient les informations suivantes :
- Genre
- Âge
- Programme d'études
- Année d'études
- Moyenne cumulative des notes (CGPA)
- Indicateurs de dépression, anxiété, attaques de panique
- Traitement spécialisé pour la santé mentale

## Prétraitement des Données
- Nettoyage des valeurs manquantes
- Normalisation des données
- Encodage des variables catégoriques

## Modèles Utilisés
Trois algorithmes de Machine Learning ont été testés :
1. **Régression Logistique**
2. **Random Forest**
3. **SVM (Support Vector Machine)**

## Comparaison des Résultats
Les performances des modèles ont été comparées selon :
- La précision
- Le rappel
- La matrice de confusion
- L'AUC-ROC
